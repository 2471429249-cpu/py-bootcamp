# 排序

> 一句话：`sorted(数据, key=规则, reverse=真假)` 是排序的万能公式；`key` 决定"按什么比"，`reverse` 决定方向。

## 1. `sorted()` vs `list.sort()`

| 方式 | 返回 | 是否改原列表 | 适用 |
| --- | --- | --- | --- |
| `sorted(data)` | 新列表 | 否 | 任何可迭代对象（list/dict.items/tuple/字符串） |
| `data.sort()` | `None` | 是（原地排序） | 只能用于 list |

> ⚠️ **易错点**：`a = a.sort()` 会让 `a` 变成 `None`！`sort()` 没有返回值。

## 2. 三个核心参数

```python
sorted(数据, key=规则, reverse=真假)
```

| 参数 | 作用 | 说明 |
| --- | --- | --- |
| 第 1 个：数据 | 排序对象 | **必填**，可迭代对象 |
| `key=` | 排序规则 | 一个函数/方法/公式，决定"按什么比较" |
| `reverse=` | 排序方向 | `False` 正序（默认可省略）、`True` 倒序 |

## 3. `key=` 的四种常见用法

```python
nums = [3, -5, 1, -2]

sorted(nums)                    # [-5, -2, 1, 3]   默认按值
sorted(nums, key=abs)           # [1, -2, 3, -5]   按绝对值
sorted(["aaa", "b", "cc"], key=len)   # 按长度
sorted(people, key=lambda x: x["age"])       # 按字典某个字段
sorted(people, key=lambda p: p[1])           # 按元组第 2 项
```

**多级排序**：`key` 返回元组 → 先按第一项，打平再按第二项：

```python
sorted(people, key=lambda x: (x[1], x[2]))   # 先按工资，工资一样按年龄
```

## 4. 按词频排序（词频统计核心）

```python
sorted(dict1.items(), key=lambda x: x[1], reverse=True)[:3]
```

> ⚠️ **易错点**：对字典排序必须加 `.items()`；直接 `sorted(dict1)` 排的是键。

## 5. 常见错误对照

```python
sorted("hello")                     # ['e','h','l','l','o'] 字符串也能排序
sorted([3, 1, 2], reverse=True)      # [3, 2, 1] 倒序
sorted({"b": 2, "a": 1}.items())     # [('a', 1), ('b', 2)] 按键排序
```

## ⚠️ 易错点速记

1. `sort()` 原地返回 `None`，别赋值
2. 字典排序加 `.items()` + `key=lambda x: x[1]`
3. `key` 必须是函数（`abs`、`len`、`lambda`），不能直接写 `key=1`
4. `reverse` 是布尔值，不是 `reverse="desc"`
