# 列表与元组

> 一句话：list 是**可变**的有序序列（日常主力），tuple 是**不可变**的有序序列（表达"不该被改"的数据，更安全）。

## 1. list（列表）常用方法

| 函数 / 方法 | 描述 |
| --- | --- |
| `len(list)` | 元素个数 |
| `max(list)` / `min(list)` | 最大值 / 最小值 |
| `list.append(obj)` | 末尾添加 |
| `list.insert(index, obj)` | 指定位置插入 |
| `list.pop()` / `list.pop(i)` | 移除并返回末尾 / 索引 i 处元素 |
| `list.remove(obj)` | 移除第一次出现的指定元素（按值删） |
| `list.index(obj)` | 查找第一次匹配的索引 |
| `list.count(obj)` | 统计出现次数 |
| `list.reverse()` | 原地反转 |
| `list.sort()` | 原地排序 |

> 常用的就 `len`、`append`、`pop`、`sort` 几个，用多了自然熟。

## 2. 增删改查基本操作

```python
a = [3, 1, 2]
a.append(4)        # [3, 1, 2, 4]
a.insert(0, 9)     # [9, 3, 1, 2, 4]
a.pop()            # 4，列表变 [9, 3, 1, 2]
a.remove(3)        # [9, 1, 2]（按值删第一次出现）
a.sort()           # [1, 2, 9]（原地排序）
```

## 3. tuple（元组）：不可变才更安全

- 与 list 类似，但**一旦初始化就不能修改**
- 没有 `append()`、`insert()`；可以按索引读，不能赋值
- 因为不可变，**代码更安全**，能表达"这组数据不该被改"的意图

```python
t = (1, 2, 3)
print(t[0])     # 1
t[0] = 9        # ❌ TypeError: 'tuple' object does not support item assignment
```

### 单元素元组的坑

```python
tuple4 = (123,)     # ✅ 单元素元组：必须有逗号
tuple4 = (123)      # ❌ 这只是整数 123（括号当普通小括号）
```

> ⚠️ **易错点**：单元素元组的逗号不能省！`(123)` 和 `(123,)` 是完全不同的东西。

## 4. 多重赋值（变量交换，01 题）

```python
a, b = 3, 7
a, b = b, a          # 交换，不需要中间变量
```

> 多重赋值是"先算右边、再同时赋值"，所以交换不会互相覆盖。生成器篇里 `a, b = b, a + b` 也是同理。

## ⚠️ 易错点速记

1. 单元素元组 `(123,)` 的逗号不能省
2. `pop()` 有返回值，`remove()` 没有
3. `sort()` 原地排序返回 `None`，`sorted()` 返回新列表
4. list 可以改、tuple 不能改；tuple 常做函数的多返回值
