# 类型注解（Type Hints）

> 一句话：**给函数和变量贴上"类型标签"**，让 IDE 和人一眼看懂，但 Python 运行时**不强制检查**。

## 1. 基本语法

> 记住口诀：**参数加冒号，返回加箭头。**

```python
def add(a: int, b: int) -> int:
    return a + b


def greet(name: str) -> str:
    return f"你好，{name}"


def log(message: str) -> None:      # 没有返回值就写 None
    print(message)
```

| 位置 | 写法 | 含义 |
| --- | --- | --- |
| 参数 | `name: str` | 参数类型 |
| 返回值 | `-> int` | 返回类型 |
| 无返回 | `-> None` | 返回 None |

## 2. 关键认知：注解只是"标签"，不强制

```python
def add(a: int, b: int) -> int:
    return a + b

print(add("a", "b"))     # ab —— 运行时不报错！注解没拦住
```

- Python **不会**因为类型不对就报错
- 注解的用处是给 **IDE / 类型检查器 / 读代码的人**看的
- 想真检查，要用 `mypy`、`pyright` 这类静态检查工具

## 3. 常用类型写法

```python
x: int = 1
price: float = 9.9
name: str = "小明"
ok: bool = True

# 容器要写元素的类型
names: list[str] = ["a", "b"]
ages: dict[str, int] = {"小明": 18}
point: tuple[int, int] = (1, 2)
ids: set[int] = {1, 2, 3}

# 可能为 None
nickname: str | None = None     # Python 3.10+ 写法
```

> 旧写法 `Optional[str]`（`from typing import Optional`）等价于 `str | None`，
> 新代码优先用 `|`。

## 4. 为什么值得写

| 收益 | 说明 |
| --- | --- |
| **IDE 补全** | 打 `x.` 时编辑器能提示该类型的方法 |
| **少写文档** | 签名本身就是最准的文档 |
| **早发现 bug** | 配合 mypy 在运行前就发现类型错误 |
| **团队协作** | 别人读你的函数不用猜参数是什么 |

## 5. 什么时候可以偷懒

- **脚本/一次性的小代码**：不写注解也行，写得清楚就好
- **公开函数 / 会被别人用的代码**：强烈建议写
- **复杂结构**：可以先用 `dict`/`list` 粗标注，别一开始就上 `TypedDict`

## ⚠️ 易错点速记

1. 注解**不强制**！`add("a","b")` 照样能跑，别以为写了 `int` 就安全
2. 返回无值写 `-> None`，不要漏
3. `list[str]` 是 Python 3.9+ 写法，老版本要 `List[str]`（`from typing import List`）
4. `str | None` 是 3.10+ 写法，老版本用 `Optional[str]`
5. 注解写错不会报错，但会误导 IDE——改代码时记得同步改注解
6. 默认参数写了注解也别忘默认值：`def f(x: int = 0) -> int:`
