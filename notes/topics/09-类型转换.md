# 类型转换

> 一句话：`input()` 永远返回字符串；要做计算必须先转换类型；转换有隐式（自动）和显式（`int()`/`float()`）两种。

## 1. 为什么要转换

```python
a = input("第一个数：")     # 用户输入 "3"，但它是字符串 "3"
b = input("第二个数：")     # "5"
print(a + b)               # "35"  ← 字符串拼接，不是相加！
print(int(a) + int(b))     # 8     ← 转成整数再算
```

> ⚠️ **易错点**：`input()` 返回**字符串**，不转换就计算会得到拼接结果或报错。

## 2. 常用显式转换

```python
int("123")        # 123      字符串 → 整数
float("3.14")     # 3.14     字符串 → 浮点数
float(3)          # 3.0      整数 → 浮点数
str(123)          # "123"    数字 → 字符串
bool(0)           # False    0/空 为 False，其余 True
```

## 3. 类型转换总表

| 方法 | 说明 |
| --- | --- |
| `int(x [,base])` | 转整数（`base` 可指定进制，如 `int("ff", 16)` → 255） |
| `float(x)` | 转浮点数 |
| `complex(real [,imag])` | 创建复数 |
| `str(x)` | 转字符串 |
| `repr(x)` | 转表达式字符串（调试用） |
| `eval(str)` | 计算字符串中的有效 Python 表达式 |
| `tuple(s)` / `list(s)` | 序列转元组 / 列表 |
| `chr(x)` | 整数 → 字符（`chr(97)` → `'a'`） |
| `ord(x)` | 字符 → 整数值（`ord('a')` → 97） |
| `hex(x)` / `oct(x)` | 整数 → 十六进制 / 八进制字符串 |

> 注：Python 3 里只有一种整数类型 `int`（长整型），没有 Python 2 的 `Long`。

## 4. 查看类型

```python
print(type(123))        # <class 'int'>
print(type("123"))      # <class 'str'>
print(type(3.14))       # <class 'float'>
```

## 5. 隐式转换（自动）

```python
3 + 5.0     # 8.0  整数自动转浮点
True + 1    # 2    True 当 1
```

> 隐式转换只发生在"安全"的场合；字符串和数字混算会直接报错，必须手动转。

## ⚠️ 易错点速记

1. `input()` 是字符串，计算前先 `int()` / `float()`
2. `int("3.14")` 会报错（字符串带小数点不能直接转 int），要先 `float()`
3. `int("abc")` 报 `ValueError` → 用户输入要配 `try/except`（见异常处理专题，待建）
4. `float` 有精度问题：`0.1 + 0.2 != 0.3`，需要精确计算用 `decimal`
