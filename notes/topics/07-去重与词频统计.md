# 去重与词频统计

> 一句话：去重保序用「判重循环」或 `dict.fromkeys`；词频统计 = 清洗 → 切分 → 字典计数 → 排序取 TopN。

## 1. 列表去重且保持原顺序（08 题）

题目：`[3, 1, 2, 3, 2, 1, 4, 4, 5, 1]` → `[3, 1, 2, 4, 5]`

### 写法一：手动判重（O(n²)，最直观）

```python
def sort1(a):
    b = []
    for x in a:
        if x not in b:
            b.append(x)
    return b
```

### 写法二：set 辅助判重（快）

```python
def sort2(a):
    b = set()
    c = []
    for x in a:
        if x not in b:
            b.add(x)
            c.append(x)
    return c
```

### 写法三：`dict.fromkeys`（最短）

```python
def sort3(a):
    return list(dict.fromkeys(a))
```

> 三种写法都是我的 `8.py` 实现 ✅
> ⚠️ 直接用 `set(a)` 会**丢失顺序**——不满足"保持原顺序"的要求（我的 `8+2.py` 就是反例）。

## 2. 词频统计完整流程（09 题）

```python
def fen(dict1):
    return sorted(dict1.items(), key=lambda x: x[1], reverse=True)[:3]

def main():
    n = input().lower().replace(",", " ").replace(".", " ").split()
    dict1 = {}
    for x in n:
        if x not in dict1:
            dict1[x] = 1
        else:
            dict1[x] += 1
    print(fen(dict1))
```

**流程拆解**：

| 步骤 | 代码 | 说明 |
| --- | --- | --- |
| 1. 读入 | `input()` | 拿到原始文本 |
| 2. 转小写 | `.lower()` | 让 `AI` 和 `ai` 算同一个词 |
| 3. 清洗标点 | `.replace(",", " ").replace(".", " ")` | **先清洗** |
| 4. 切分 | `.split()` | **后切分**，得到单词列表 |
| 5. 计数 | `dict1[x] = dict1.get(x, 0) + 1` | 字典统计词频 |
| 6. 排序取 Top3 | `sorted(d.items(), key=..., reverse=True)[:3]` | 加 `.items()` |

> ⚠️ **铁律**：先清洗、后切分。`.split()` 之后是 list，没有 `.replace()` 方法。

## 3. 标准库捷径：`collections.Counter`

```python
from collections import Counter

counter = Counter(text.lower().split())
counter.most_common(3)      # [('python', 4), ('ai', 2), ...]
dict(counter)               # 转回普通字典
```

> 学习顺序：**先手写 dict 版理解原理，再用 Counter 提速**。

## 4. 去重与统计的对比

| 任务 | 核心 | 一行写法 |
| --- | --- | --- |
| 去重保序 | 键唯一 + 插入顺序 | `list(dict.fromkeys(a))` |
| 计数 | 字典 `.get(x, 0) + 1` | `dict1[x] = dict1.get(x, 0) + 1` |
| 取 TopN | 按值排序 + 切片 | `sorted(d.items(), key=lambda x: x[1], reverse=True)[:n]` |

## ⚠️ 易错点速记

1. `set()` 去重会丢顺序，要保序用 `dict.fromkeys`
2. 先清洗标点、再 `split()`，顺序反了就报 `'list' object has no attribute 'replace'`
3. 字典排序必须 `.items()`，否则排的是键
4. `.lower()` 别忘了——大小写不统一会把同一个词拆成两个
5. 函数名 `sort1/sort2` 建议改成 `dedup1/dedup2`（去重 ≠ 排序）
