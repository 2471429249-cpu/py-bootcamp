# 函数进阶（多返回值 / 默认参数 / lambda）

> 一句话：函数能一次返回多个值（本质是元组）、默认参数有**可变对象陷阱**、`lambda` 只能是单个表达式——这三个都是面试高频。

## 1. 函数可以返回多个值

```python
def division(num1, num2):
    """求商与余数"""
    a = num1 % num2
    b = (num1 - a) / num2
    return b, a          # 其实是返回了一个元组 (b, a)


quotient, remainder = division(9, 4)
print(quotient, remainder)   # 2.0 1

t = division(9, 4)
print(t)                     # (2.0, 1)
```

- `return b, a` 返回的是**元组** `(b, a)`
- 调用方可以**直接解包**成两个变量 → `quotient, remainder = ...`
- 也可以**整个接收**一个 tuple → `t = ...`

> 💡 「Python 一次接受多个返回值的数据类型就是元组。」这是相比其他语言的一个简便特性。

## 2. ⚠️ 可变对象做默认参数的陷阱（面试常考）

```python
# ❌ 千万别这么写
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket

print(add_item("a"))   # ['a']
print(add_item("b"))   # ['a', 'b']  ← 上一次的 "a" 还在！
```

原因：

- 默认值**只在函数定义时创建一次**，之后所有调用共用同一个列表对象
- `list` / `dict` / `set` 是**可变**的，`append` 是**原地修改**，改的就是那个共享的默认值
- 而 `a=10`、`s="hello"` 这种不可变值，你只能让变量**重新指向**新值，动不到"老值"

✅ 正确写法——用 `None` 占位：

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []      # 每次调用都新建一个
    bucket.append(item)
    return bucket
```

> **记住这个面试常考点**：在 Python 函数里，永远不要用 `[]`、`{}`、`set()` 直接做默认参数！一律用 `None` 代替。

## 3. `lambda` 的限制

```python
square = lambda x: x * x      # 等价于 def square(x): return x * x
```

> ⚠️ `lambda` 表达式**只能是一个表达式**：不能写 `if`/`else` 多分支（虽然能写三元表达式）、不能写循环、不能写 `return`。

```python
# ✅ 可以：三元表达式
grade = lambda s: "及格" if s >= 60 else "不及格"

# ❌ 不行：多分支 / 循环 / return 语句
```

**如果逻辑稍复杂一点，老老实实用 `def`，不要硬塞进 `lambda`。**

## 4. 什么时候该用 lambda

| 场景 | 建议 |
| --- | --- |
| 传给 `sorted(key=...)`、`max(key=...)` 这种一次性小函数 | 用 `lambda` |
| 需要多行逻辑、分支、循环 | 用 `def` |
| 需要复用、需要命名、需要写文档 | 用 `def` |

```python
students = [{"name": "小明", "score": 92}, {"name": "小红", "score": 85}]
students.sort(key=lambda s: s["score"])   # 一行搞定，不需要 def
```

## ⚠️ 易错点速记

1. `return a, b` 返回的是**元组**，不是"两个返回值"
2. 解包时变量个数必须和元组长度一致
3. 可变默认参数 `def f(x, lst=[])` → 默认值被所有调用共享，必须用 `None`
4. `lambda` 只能写表达式，写不了语句（`return`、`for`、多分支）
5. `lambda` 里不要塞复杂逻辑，可读性比"一行"重要
