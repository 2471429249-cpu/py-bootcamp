# 特殊方法与哈希（`__eq__` / `__hash__`）

> 一句话：**重写了 `__eq__`，Python 会自动把 `__hash__` 设为 `None`**——对象就再也放不进 `set` / `dict` 的 key 了。

## 1. `__hash__` 的小坑（今天的重点）

> 只要你重写了 `__eq__`，Python 会**自动把 `__hash__` 设为 None**——也就是说，这个对象不能再放进 `set` / `dict` 的 key。

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __eq__(self, other):
        return isinstance(other, Point) and (self.x, self.y) == (other.x, other.y)


{Point(1, 2)}     # ❌ TypeError: unhashable type: 'Point'
```

**为什么 Python 要这么设计？**

- `set` / `dict` 靠**哈希值**找元素，再用 `==` 确认
- 如果两个对象 `__eq__` 相等但哈希值不同，`set` 里会出现"看起来重复却删不掉"的诡异 bug
- 所以 Python 干脆要求：**你要自定义"相等"，就必须自己保证"哈希一致"**；不写就当不可哈希

## 2. 正确写法：手动补上 `__hash__`

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __eq__(self, other):
        return isinstance(other, Point) and (self.x, self.y) == (other.x, other.y)

    def __hash__(self):
        # 用「参与 __eq__ 比较的那些字段」组成元组来算哈希
        return hash((self.x, self.y))


p1, p2 = Point(1, 2), Point(1, 2)
print(p1 == p2)          # True
print(len({p1, p2}))     # 1  ← 去重成功
print({p1: "点A"}[p2])   # 点A ← 能当 dict 的 key
```

**核心原则**：`__eq__` 用哪些字段比较，`__hash__` 就用哪些字段算哈希。

## 3. 什么是"可哈希"

| 类型 | 可哈希？ |
| --- | --- |
| `int` / `float` / `str` / `bool` / `None` | ✅ |
| `tuple`（元素都可哈希时） | ✅ |
| `frozenset` | ✅ |
| `list` / `dict` / `set` | ❌ 可变的都不行 |
| 自定义类 | 默认按 `id()` 哈希；**重写 `__eq__` 后就变 None** |

```python
{1, "a", (1, 2)}      # ✅ 都可以
{[1, 2]}              # ❌ TypeError: unhashable type: 'list'
```

## 4. 常用特殊方法速查

| 方法 | 触发时机 |
| --- | --- |
| `__init__` | 创建实例 |
| `__eq__` | `==` |
| `__hash__` | `hash()`、放进 `set` / `dict` 的 key |
| `__str__` | `print()` / `str()` |
| `__repr__` | 调试时直接输入对象 |
| `__len__` | `len()` |
| `__add__` | `+` |
| `__iter__` / `__next__` | 迭代（配合 `for`） |

## ⚠️ 易错点速记

1. 重写 `__eq__` 而忘了 `__hash__` → 对象**不可哈希**，放进 `set` 直接报 `TypeError`
2. `__eq__` 和 `__hash__` 必须**用同一组字段**，否则会出"查不到 / 删不掉"的怪问题
3. 可变对象（`list`/`dict`/`set`）**天然不可哈希**，不能当 `dict` 的 key
4. 重写 `__eq__` 时先判断 `isinstance(other, 类名)`，避免和别的类型比较时崩掉
5. 想打印好看要写 `__str__`，调试方便要写 `__repr__`（两者别混）
