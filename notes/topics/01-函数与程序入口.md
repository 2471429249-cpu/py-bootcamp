# 函数与程序入口

> 一句话：把代码封装成可复用的**函数**，并用 `if __name__ == "__main__":` 区分「直接运行」和「被导入」。

## 1. 函数定义与调用

```python
def jia(a, b):        # def 函数名(参数):
    return a + b      # return 返回结果

print(jia(3, 7))      # 10
```

- 参数是函数接收的输入；`return` 是函数的输出（没有 return 就返回 `None`）
- 函数先定义、后调用；调用时按位置或按关键字传参

## 2. 函数参数不要「白写」

```python
def main(a, b):                     # ① 定义时要求传 2 个参数
    print("jisuan")
    a = float(input("第一个数："))   # ② 立刻把 a 覆盖了
    b = float(input("第二个数字"))   # ③ 立刻把 b 覆盖了
```

```python
def main(a, b):
    a = 100
    b = 200
    print(a, b)

main(1, 2)       # 输出 100 200
main(999, 888)   # 还是输出 100 200
```

> ⚠️ **易错点**：参数一旦在函数体内被 `input()` 重新赋值，调用者传进来的值就白传了。
> **规则：参数要么真用，要么别定义。**

## 3. `if __name__ == "__main__":` 是什么

```python
if __name__ == "__main__":
    main()
```

> **翻译成人话**：如果这个文件是被**直接运行**的，那就执行 `main()`；如果是被 **import** 的，就别执行。

- `__name__` 是 Python 自动给每个文件起的名字
- 直接运行 → `__name__ == "__main__"` → 执行 `main()`
- 被 import → `__name__` 是模块名，不执行 → 不会「导入即运行」造成副作用

**为什么要写它**：以后写的模块既可以被别人 import 复用，又可以自己单独运行测试。

## 4. 用 `type()` 查看类型

```python
print(type(123))        # <class 'int'>
print(type("abc"))      # <class 'str'>
print(type(3.14))       # <class 'float'>
```

> 调试时先 `type()` 看一眼，很多"莫名其妙"的报错就不莫名其妙了。

## ⚠️ 易错点速记

1. 函数体内被 `input()` 覆盖 → 参数白写
2. 忘记写 `if __name__ == "__main__":` → 被 import 时会意外执行
3. 没有 `return` 的函数返回 `None`，不是空字符串
