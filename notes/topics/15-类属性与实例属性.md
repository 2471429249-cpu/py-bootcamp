# 类属性与实例属性

> 一句话：写在**类体 / `type()` 字典**里的是**类属性**（所有人共享）；写在 **`__init__` 的 `self.xxx`** 里的是**实例属性**（各存各的）。

## 1. 两种属性写在哪

```python
class Dog:
    species = "犬科"          # ← 类属性：直接写在 class 下

    def __init__(self, name, hp):
        self.name = name      # ← 实例属性：写在 __init__ 里
        self.hp = hp


d1 = Dog("旺财", 100)
d2 = Dog("大黄", 80)

print(d1.species, d2.species)   # 犬科 犬科  ← 共享同一份
print(d1.name, d2.name)         # 旺财 大黄  ← 各自一份
```

| 写法 | 名称 | 归属 |
| --- | --- | --- |
| `class` 下直接赋值 / `type()` 第三个参数（属性字典） | 类属性 | **所有实例共享** |
| `__init__` 里 `self.xxx = ...` | 实例属性 | **每个实例各存各的** |

> 用你自己的话说：
> - 类属性「所有人共享，**改一处，全遭殃**」——适合存常量，比如圆周率
> - 实例属性「各存各的，**互不干扰**」——适合存每个人的名字、年龄、血量

## 2. 查找顺序：先找实例，再找类

```python
class Dog:
    species = "犬科"

d = Dog()
print(d.species)        # 犬科（实例上没有 → 去类里找）
d.species = "猫科"       # ← 这是在【实例上】新建了一个属性
print(d.species)        # 猫科（实例自己的）
print(Dog.species)      # 犬科（类属性没变）
```

> ⚠️ `d.species = "猫科"` **没有修改类属性**，只是在实例上「遮蔽」了它。

## 3. 修改类属性：必须通过类名

```python
class Dog:
    species = "犬科"

d1, d2 = Dog(), Dog()

Dog.species = "猫科"     # ✅ 通过类名改 → 对所有实例生效
print(d1.species, d2.species)    # 猫科 猫科
```

## 4. ⚠️ 最坑的地方：可变的类属性

```python
class Dog:
    tricks = []          # ❌ 可变对象做类属性

    def add_trick(self, t):
        self.tricks.append(t)


a, b = Dog(), Dog()
a.add_trick("坐下")
print(b.tricks)          # ['坐下']  ← b 也被污染了！
```

原因：`self.tricks.append(...)` 是**原地修改**，改的是**共享的那一个列表**。

✅ 正确写法——放到 `__init__` 里：

```python
class Dog:
    def __init__(self):
        self.tricks = []      # ✅ 每个实例各自一份

    def add_trick(self, t):
        self.tricks.append(t)


a, b = Dog(), Dog()
a.add_trick("坐下")
print(b.tricks)          # []  ← 互不干扰
```

> 这和 [11-函数进阶](11-函数进阶.md) 里「可变默认参数陷阱」是**同一个坑**：可变对象被共享了。

## 5. 常见用途对照

| 想存什么 | 放哪 | 例子 |
| --- | --- | --- |
| 所有实例共用的常量 | 类属性 | `PI = 3.14159`、`species = "犬科"` |
| 计数器（统计创建了多少实例） | 类属性 | `Dog.count += 1` |
| 每个对象自己的数据 | 实例属性 | `self.name`、`self.hp` |
| 每个对象自己的可变容器 | 实例属性（在 `__init__` 建） | `self.tricks = []` |

统计实例个数：

```python
class Dog:
    count = 0                 # 类属性做计数器

    def __init__(self, name):
        self.name = name
        Dog.count += 1        # 注意：用类名 +=，别用 self.count +=

Dog("旺财"); Dog("大黄")
print(Dog.count)              # 2
```

## ⚠️ 易错点速记

1. `self.xxx = ...` 写在方法里 → **实例属性**；直接写在 class 下 → **类属性**
2. `d.attr = v` 只是在实例上遮蔽，**不会改类属性**；改类属性要用 `类名.attr = v`
3. **可变对象（list/dict/set）不要做类属性**，会被所有实例共享 → 放到 `__init__`
4. 类属性计数器要写 `Dog.count += 1`，不要写 `self.count += 1`（后者会建出实例属性）
5. 查找顺序：实例属性 → 类属性 → 父类，所以「看起来能读到」不代表「改的是同一个」
