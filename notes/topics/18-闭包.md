# 闭包

> 一句话：闭包就是**函数里套函数，内层函数"记住"了外层函数的变量**——是函数的一种妙用，不是什么新知识。

## 1. 什么是闭包

闭包要同时满足三个条件：

1. 有**嵌套函数**（函数里面再定义函数）
2. 内部函数**引用了外层函数的变量**
3. 外层函数**把内部函数返回**出来

```python
def make_counter():
    count = 0                    # 外层函数的局部变量

    def counter():               # 内部函数（嵌套）
        nonlocal count           # 声明要修改外层的 count
        count += 1
        return count

    return counter               # 返回内部函数本身（不加括号！）


c1 = make_counter()              # c1 就是那个内部函数
print(c1())                      # 1
print(c1())                      # 2
print(c1())                      # 3
```

关键：`make_counter()` 早就返回了，按理说 `count` 这个局部变量应该被销毁——但它**没有被销毁**，因为内部函数还"抓"着它。这个被记住的 `count` 就叫**自由变量**。

> 用你自己的话说：**闭包其实就是一种函数的妙用**——一个函数"打包带走"了它定义时环境里的变量。

## 2. 闭包的作用：带记忆的函数

不同计数器实例各记各的：

```python
c1 = make_counter()
c2 = make_counter()
print(c1(), c1())      # 1 2
print(c2())            # 1   ← c2 是独立的，互不影响
```

用这个特性可以做：计数器、累加器、缓存、配置开关等"有状态"的小函数。

## 3. `nonlocal`：修改外层变量必须声明

```python
def outer():
    x = 0
    def inner():
        # x += 1          # ❌ 直接写会报错：引用前未定义
        nonlocal x        # ✅ 先声明 x 是外层的变量
        x += 1
        return x
    return inner
```

> `nonlocal` 声明**写在内部函数里**，但声明的是**外层函数里定义的变量**（所以它出现在内部嵌套函数"外面"的那个作用域）。
> 如果只是**读**外层变量，不用 nonlocal；只有**赋值/修改**才需要。

## 4. 闭包与装饰器的关系（重点）

**装饰器就是闭包的典型应用**。比如一个计时装饰器 `insert_time`：

```python
import time

def insert_time(func):                  # 外层函数：接收被装饰的函数
    def wrapper(*args, **kwargs):       # 内部函数（闭包）：抓住 func
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"耗时 {end - start:.4f} 秒")
        return result
    return wrapper                       # 返回闭包


@insert_time
def test():
    time.sleep(0.5)
    print("test 运行")


test()
```

理解这个执行流程（这就是你笔记里"除了第一次调用"那半句的意思）：

1. Python 执行到 `@insert_time` 时，会**调用一次** `insert_time(test)`——这是**第一次调用**
2. 它返回内部的 `wrapper` 闭包，并用它**替换**掉原来的 `test`
3. 之后你每次 `test()`，其实调用的都是这个 `wrapper`（闭包）——所以「**其余调用都是在调用 insert_time 返回的那个内部函数**」

> ⚠️ 装饰器 `@insert_time` 写在被装饰函数定义的**外面（上方）**；真正"干活"的 `wrapper` 是嵌套在 `insert_time` **里面**的函数。

## 5. 常见坑

### 坑 1：参数名不能重复

```python
def outer(x):
    def inner(x):        # ❌ 内层参数 x 把外层的 x 挡住了（遮蔽）
        return x
    return inner
```

> 闭包里**各个函数里的参数不能重复**——内外层函数如果用了同名参数，内层会"遮蔽"外层，你就拿不到想抓的自由变量了。给它们取不同的名字。

### 坑 2：返回函数忘了不加括号

```python
def outer():
    def inner():
        return 1
    return inner       # ✅ 返回函数对象

# return inner() 是返回 1（int），不是闭包
```

### 坑 3：循环里创建闭包的老陷阱（延迟绑定）

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)      # 都引用同一个 i
print([f() for f in funcs])      # [2, 2, 2]，不是 [0, 1, 2]
```

> 原因：闭包记住的是**变量名**，不是当时的值；循环结束后 `i` 已经是 2。
> 解决：用默认参数把值"固定"下来——`lambda i=i: i`。

## ⚠️ 易错点速记

1. 闭包 = 嵌套函数 + 引用外层变量 + 外层返回内层，缺一不可
2. 读外层变量不用 `nonlocal`，**修改**才必须声明
3. `return inner` 不加括号；`return inner()` 就成普通返回了
4. 内外层函数**参数名别重复**，会遮蔽
5. 循环里用 lambda 造闭包，注意延迟绑定（用默认参数 `i=i` 固定）
6. 装饰器 = 闭包 + 函数作参数；`@` 那一行只执行一次
