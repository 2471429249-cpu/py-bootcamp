# 字符串与格式化

> 一句话：字符串是 Python 最常用的数据类型；`f-string` 是输出格式化的主力，切片是字符串的"瑞士军刀"。

## 1. f-string 的 `f` 不能丢

```python
print("{i}")     # ❌ 少写 f：原样输出 {i}
print(f"{i}")    # ✅ 正确：把 i 的值插进去
```

- `f""` 前缀 = 格式化字符串，`{}` 里写变量或表达式
- 忘了 `f` **不会报错**，但结果是错的——这是最隐蔽的坑

## 2. 数字格式化

```python
amount = 1234567890
print(f'订单金额：{amount:,} 元')      # 订单金额：1,234,567,890 元
```

```python
# :<3 表示左对齐、占 3 个字符宽度，让表整齐
print(f"{j}×{i}={i * j:<3}", end="  ")
```

| 格式 | 含义 | 示例 |
| --- | --- | --- |
| `:,` | 千分位逗号 | `1,234,567,890` |
| `:<3` | 左对齐、宽 3 字符 | `3  ` |
| `:>3` | 右对齐、宽 3 字符 | `  3` |
| `:^3` | 居中、宽 3 字符 | ` 3 ` |
| `:.2f` | 保留两位小数 | `2.50` |

> ⚠️ **易错点**：九九乘法表对齐靠「`:<3` 定宽 + `end` 控制行内间距」，少任何一个都会歪。

## 3. 字符串切片与反转（07 题）

```python
s = "hello, 世界"

# 方法 1：切片步长 -1（最优雅）
print("切片反转：", s[::-1])

# 方法 2：reversed + join
print("reversed: ", "".join(reversed(s)))
```

- `s[::-1]` = 从头到尾、步长 -1 = 反转
- `reversed(s)` 返回迭代器，要 `"".join()` 拼回字符串
- 中文等 Unicode 字符用这两种方法反转也完全正确

## 4. 文本清洗铁律：先清洗，后切分

```python
# ❌ 错误：split() 之后已是列表，列表没有 replace()
n = input().lower().split().replace(",", " ")

# ✅ 正确：输入 → 转小写 → 替换标点 → 最后切分
n = input().lower().replace(",", " ").replace(".", " ").split()
```

> ⚠️ **易错点**：报错 `'list' object has no attribute 'replace'` 就是顺序反了。
> **口诀：先清洗，后切分。**

## 5. 常用字符串方法速查

| 方法 | 作用 |
| --- | --- |
| `s.lower()` / `s.upper()` | 转小写 / 大写 |
| `s.split(sep)` | 按分隔符切分成列表 |
| `s.replace(old, new)` | 替换子串（返回新字符串） |
| `s.strip()` | 去掉首尾空白 |
| `s.join(seq)` | 用 s 连接序列 |
| `len(s)` | 长度 |
| `s.startswith(x)` / `s.endswith(x)` | 是否以 x 开头 / 结尾 |

## ⚠️ 易错点速记

1. f-string 漏写 `f` → 不报错但结果错
2. `split()` 之后是 list，不能再 `.replace()`——先清洗后切分
3. `s[::-1]` 是反转；`s[::2]` 是隔一个取一个，别混
4. 字符串不可变：所有方法返回新字符串，不会改原串
