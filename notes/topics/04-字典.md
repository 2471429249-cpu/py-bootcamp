# 字典

> 一句话：字典是「键值对」容器，按键查找接近 O(1)；取值用 `.get()` 更安全，排序要加 `.items()`。

## 1. 基本操作

```python
name = {"小明": 18, "小红": 20}
name["小明"]          # 18
name["小刚"] = 22     # 新增
name.keys()           # 所有键
name.values()         # 所有值
name.items()          # 键值对（排序时必用）
```

## 2. 取值：`dict.get()` vs `dict[key]`

```python
name.get('六点水')      # None，不会报错
name['六点水']          # ❌ KeyError!
```

> ⚠️ **易错点**：不确定 key 是否存在时，用 `name.get(key)`；要设默认值就 `name.get(key, 0)`。

## 3. `dict.fromkeys(seq)`：生成字典

把序列里的每个元素当**键**，没指定值的时候，值默认都是 `None`：

```python
list(dict.fromkeys([3, 1, 2, 3, 2]))   # [3, 1, 2] —— 去重且保持原顺序
```

> 妙用：因为字典的键唯一且（Python 3.7+）保持插入顺序，`dict.fromkeys` 成了最短的"去重保序"写法。

## 4. 字典统计（词频统计的核心）

```python
freq = {}
for word in text.lower().split():
    freq[word] = freq.get(word, 0) + 1   # 出现一次 +1，没有就按 0 开始
```

## 5. 字典排序：必须加 `.items()`

```python
sorted(dict1.items(), key=lambda x: x[1], reverse=True)[:3]
```

> ⚠️ **易错点**：直接 `sorted(dict1)` 排的是**键**（按字母），不是词频！
> `.items()` 才是把「键值对」拿出来按 `x[1]`（值）排序。

## 6. `collections.Counter`（标准库捷径）

```python
from collections import Counter
counter = Counter(text.lower().split())
counter.most_common(3)      # 出现最多的 3 个词
```

> 先手写 `dict` 版理解原理，再用 Counter 提速。

## ⚠️ 易错点速记

1. 用 `[]` 取不存在的键 → `KeyError`；用 `.get()` 返回 `None`
2. `sorted(d)` 排键；排序值必须 `.items()` + `key=lambda x: x[1]`
3. `dict.fromkeys` 的值默认是 `None`，不是 0
4. 字典的键必须可哈希（list 不能当键）
