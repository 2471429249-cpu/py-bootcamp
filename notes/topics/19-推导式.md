# 推导式

> 一句话：**一行代码把一个序列变成另一个序列**——`[表达式 for 变量 in 可迭代对象 if 条件]`。

## 1. 通用结构

```python
[表达式 for 变量 in 可迭代对象 if 条件]
```

三段分别是什么意思：

| 部分 | 含义 |
| --- | --- |
| **表达式** | 每个元素被收集前要做什么变换（不变换就直接写变量名） |
| **for … in** | 遍历哪个序列 |
| **if** | 可选过滤条件，不需要就省略 |

## 2. 列表推导式

```python
# 普通写法
squares = []
for x in range(5):
    squares.append(x * x)

# 推导式写法
squares = [x * x for x in range(5)]
print(squares)          # [0, 1, 4, 9, 16]
```

**带过滤条件**：

```python
evens = [x for x in range(10) if x % 2 == 0]
print(evens)            # [0, 2, 4, 6, 8]
```

**带变换 + 过滤**：

```python
# 取所有偶数，并各自平方
result = [x * x for x in range(10) if x % 2 == 0]
print(result)           # [0, 4, 16, 36, 64]
```

## 3. 字典推导式

> 结构：`{键: 值 for 变量 in 可迭代对象}`

```python
prices = {'apple': 5, 'banana': 3, 'cherry': 10}

# 所有价格翻倍
doubled = {k: v * 2 for k, v in prices.items()}
print(doubled)          # {'apple': 10, 'banana': 6, 'cherry': 20}
```

**带条件**：

```python
expensive = {k: v for k, v in prices.items() if v > 4}
print(expensive)        # {'apple': 5, 'cherry': 10}
```

**键值互换**（值不重复时）：

```python
flipped = {v: k for k, v in prices.items()}
```

> ⚠️ 字典推导式必须写 `键: 值`，只写一个值会变成**集合推导式**。

## 4. 集合推导式

```python
words = ['apple', 'banana', 'apple', 'cherry']
initials = {w[0] for w in words}       # 自动去重
print(initials)      # {'a', 'b', 'c'}
```

## 5. 生成器表达式（圆括号）

把 `[]` 换成 `()` 就是生成器——**边算边给，不占内存**：

```python
gen = (x * x for x in range(1000000))   # 立刻返回，不计算
print(next(gen))                         # 0

total = sum(x * x for x in range(100))   # 常用于 sum/max/min 等聚合
```

详见 [08-生成器](08-生成器.md)。

## 6. 什么时候别用推导式

**推导式只适合"一行能说清"的场景**。如果逻辑超过一层，写成 for 循环更可读：

```python
# ❌ 能写但难读
result = [f(x) if x > 0 else g(x) for x in data if x is not None and check(x)]

# ✅ 清楚得多
result = []
for x in data:
    if x is not None and check(x):
        result.append(f(x) if x > 0 else g(x))
```

## ⚠️ 易错点速记

1. 推导式里的 `if` 是**过滤**（决定要不要这个元素），不是 if/else 分支
2. 字典推导式漏写 `键:` 会变成集合推导式
3. 推导式里的变量**不会泄漏**到外面（Python 3）
4. 嵌套层数超过 2 层就别用推导式了，可读性掉太厉害
5. `()` 是生成器表达式，不是元组推导式（根本不存在元组推导式）
6. 推导式里别调用有副作用的函数（如 print/append），那不是它的用途
