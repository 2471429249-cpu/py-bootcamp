## 手写要点（正文段落，原文照录）

1. 「你自己定义一个普通类，那就是个"装变量的盒子"。用 Enum 继承，相当于给这个盒子上了防伪标签、防盗锁、说明书（name/value），并且杜绝了任何拼写错误和恶意篡改的可能。这就是为什么只要涉及到"固定的选项/状态"，就一定要用 Enum 的原因。还有 enum 可以直接用 name 和 value」
2. 「for 循环就是 Python 里最标准、最常用的迭代方式。」
3. 「一切对象都源自类，一切类都源自 type」
4. 「type（）所有 class 的类型都是'type'」
5. 「写在 type() 的字典里，或直接写在 class 下的：是类属性。所有人共享，改一处，全遭殃。（适合存常量，比如圆周率）」
6. 「写在 `__init__` 里的 self.xxx：是实例属性。各存各的，互不干扰。（适合存每个人的名字、年龄、血量）」
7. 「可以理解为元类的创立是一个中转站，当你建立一个类时，你需要经过它并按照它的要求被迫强制修改」
8. 「创建线程：名字 = threading.Thread(target=方法)」
9. 「名字是线程名，方法是该线程调用的方法」
10. 「给deepseek：当你看到这行，去给我的笔记里加上线程和进程的知识点，太多了，只要我能用上的，比如condition都加上去」

## 图 image35

知识点：**什么时候用枚举**——凡是「这个变量只能取这几个值」的代码，都该考虑 Enum。

4、什么时候用枚举？

总结一下：当你写下任何一段「这个变量只能取下面这几个值」的代码时，就应该考虑 `Enum`。

- ✓ 状态机的状态：`Pending` / `Running` / `Done` / `Failed`
- ✓ 类别 / 枚举类型：颜色、性别、文件类型
- ✓ 优先级 / 等级：用 `IntEnum`，可以排序和比较

代替散落的 `STATUS_PENDING = 0` 这种「字符串/整数魔法值」，让代码更安全、更清晰。

> **转写说明**：标题为「4、什么时候用枚举？」。列表三项前为对勾符号 ✓；「状态机的状态」「类别 / 枚举类型」「优先级 / 等级」加粗。
> 末段 `Enum`、`IntEnum`、`STATUS_PENDING = 0` 均为浅灰圆角底行内代码样式。

## 图 image36

知识点：**`type()` 的第二种用法——传三个参数动态造类**。

既然 `type` 是创建类的元类，那我们能不能**直接调用 `type` 来造一个类**？答案是能。

`type()` 还有第二种用法——传三个参数：

```python
type(类名, 父类元组, 属性字典)
```

| 参数 | 说明 |
| --- | --- |
| 类名 | 字符串，例如 `'Hello'` |
| 父类元组 | 单父类要写成单元组：`(object,)`，多继承就多个 |
| 属性字典 | `{'方法名': 函数, '属性名': 值}` |

> **转写说明**：代码块左上角有语言标签 `PYTHON`、右上角有「复制」按钮。「直接调用 `type` 来造一个类」加粗。
> 「类名」「父类元组」「属性字典」三行为表格首列，`'Hello'`、`(object,)`、`{'方法名': 函数, '属性名': 值}` 为行内代码样式。

## 图 image37

知识点：**`threading.Thread` 怎么给线程传参——`args`（元组）与 `kwargs`（字典）**。

代码（带行号的编辑器截图，第 20~25 行）：

```python
if __name__ == '__main__':
    # args：以元组的方式给执行任务传递参数
    sing_thread = threading.Thread(target=sing, args=(3,))
    # kwargs：以字典方式给执行任务传递参数
    dance_thread = threading.Thread(target=dance, kwargs={"count": 2})
```

> **转写说明**：第 24 行在原图中有黄色高亮底（表示当前选中/断点行）。第 20 行左侧有绿色调试三角标记。
> 第 21、23 行为浅色注释。`args=(3,)` 是**单元素元组**，末尾逗号不能省（否则变成整数 3）。
