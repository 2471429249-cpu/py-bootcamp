## 图 note30

知识点：List（列表）最常用的函数与方法对照表，并给出“只记 len / append / pop / sort 就够用”的实用建议。

### 7、List（列表）函数 & 方法

最常用的几个：

| 函数 / 方法 | 描述 |
| --- | --- |
| `len(list)` | 列表元素个数 |
| `max(list)` | 返回列表元素最大值 |
| `min(list)` | 返回列表元素最小值 |
| `list.append(obj)` | 在列表末尾添加新的对象 |
| `list.insert(index, obj)` | 将对象插入指定位置 |
| `list.pop()` | 移除并返回列表最后一个元素 |
| `list.pop(i)` | 移除并返回索引 `i` 处的元素 |
| `list.remove(obj)` | 移除列表中第一次出现的指定元素（按值删） |
| `list.index(obj)` | 从列表中找出某个值第一次匹配的索引位置 |
| `list.count(obj)` | 统计某个元素在列表中出现的次数 |
| `list.reverse()` | 反向列表中元素（原地） |
| `list.sort()` | 对原列表排序（原地） |

记不住没关系，常用的就是 `len`、`append`、`pop`、`sort` 这几个，用多了自然熟。

## 图 note31

知识点：元组（tuple）是与 List 类似的有序序列，但一旦初始化就不能修改；正因为它不可变，所以代码更安全。

### 1、什么是元组（tuple）

上一节刚说了一个有序列表 List，现在说另一种有序列表叫元组：tuple。

tuple 和 List 非常类似，但是 tuple **一旦初始化就不能修改**。也就是说元组（tuple）是不可变的——它没有 `append()`、`insert()` 这样的方法，可以通过索引读，但不能赋值。

那么为什么要有 tuple 呢？

那是因为 tuple 是不可变的，所以**代码更安全**。所以建议能用 tuple 代替 list 就尽量用 tuple。

## 图 note32

知识点：单元素元组必须写成 `(123,)` 这种带逗号的形式，否则括号只会被当成普通的小括号表达式。

元组中只包含一个元素时，**需要在元素后面添加逗号**：

```python
tuple4 = (123,)
```

如果不加逗号，创建出来的就不是元组（tuple），而是指 `123` 这个整数了。

这是因为括号 `()` 既可以表示元组，又可以表示数学公式中的小括号——产生了歧义。所以 Python 规定，单元素的时候不加逗号就按小括号算（表达式），加了逗号才是元组。

## 图 note33

知识点：取字典值时，不确定 key 是否存在就用 `dict.get(key)`，避免 `dict[key]` 抛 `KeyError`。

> “⚠️注意：如果字典中没有这个键，直接 `dict[key]` 会报错（`KeyError`）。如果不确定 key 是否存在，更安全的写法是 `dict.get(key)` ——找不到时返回 `None`，不报错。”

```python
name.get('六点水')      # None, 不会报错
name['六点水']          # KeyError!
```

## 图 note34

知识点：空 set 只能用 `set()` 创建，写成 `{}` 得到的是空字典 dict。

> “⚠️ 空 set 不能写成 `{}` —— 那会创建一个空 dict。空 set 必须用 `set()` ：”

```python
empty_set = set()        # ✓ 空 set
empty_dict = {}          # ✗ 这是空 dict
```

## 图 note35

知识点：`remove` 报错是一种保护机制，能在错误发生点立刻暴露问题；用 `discard` 则会静默通过、把 bug 带到后面。

### 1. 报错能帮你抓出 Bug

`remove` 报错其实是一种保护机制。如果代码逻辑里认定“这个元素肯定在”，结果它不在，说明前面的代码出错了。这时候报错能让你立刻发现问题；如果用了 `discard`，程序悄无声息地跑过去了，最后得出一个错误结果，你反而很难排查。

## 图 note36

知识点：两个 set 之间支持并集、交集、差集、对称差四种集合运算，分别对应 `|`、`&`、`-`、`^`。

### 4、set 的集合运算

因为 set 是一个无序不重复元素集，所以两个 set 可以做数学意义上的 **并集（union）**、**交集（intersection）**、**差集（difference）** 等操作。

| 运算 | 符号 | 含义 |
| --- | --- | --- |
| 交集 | `a & b` | a 和 b 都有的元素 |
| 并集 | `a \| b` | a 和 b 任一有的元素（去重） |
| 差集 | `a - b` | a 有但 b 没有的元素 |
| 对称差 | `a ^ b` | 仅在 a 或仅在 b 中的元素（不要两个都有的） |
