## 图 image28

知识点：**函数可以返回多个值**——本质是返回一个元组，调用方可解包。

代码块（左上角语言标签 `PYTHON`，右上角有「复制」「▶ 试运行」两个按钮）：

```python
def division(num1, num2):
    """求商与余数"""
    a = num1 % num2
    b = (num1 - a) / num2
    return b, a


quotient, remainder = division(9, 4)
print(quotient, remainder)

t = division(9, 4)
print(t)
```

输出：

```text
2.0 1
(2.0, 1)
```

观察一下——函数 `return b, a` 实际上是返回了一个**元组（tuple）** `(b, a)`，调用方可以直接「解包」赋给两个变量，也可以整个拿到一个 tuple。

> 💡 「Python 一次接受多个返回值的数据类型就是元组。」这是相比其他语言的一个简便特性。

> **转写说明**：`return b, a` 与 `(b, a)` 在原图中为浅灰圆角底的行内代码样式。代码块中 `a = num1 % num2` 求余数、
> `b = (num1 - a) / num2` 求商（注意用 `/` 得到浮点数，所以输出是 `2.0` 而不是 `2`）。

## 图 image29

知识点：**可变默认参数陷阱**——不要用 `[]`、`{}`、`set()` 直接做默认参数。

- 如果你的默认值是 `a=10` 或 `s="hello"`，你在函数里修改不了它们（你只能让变量重新指向一个新值），所以那个固定的「老值」永远不会被污染。
- 只有**可变的**（`list`、`dict`、`set`），你可以在**原地**修改它（比如 `append`），才会导致「默认值」被偷偷改变。

**记住这个面试常考点**：在 Python 函数里，永远不要用 `[]`、`{}`、`set()` 直接做默认参数！一律用 `None` 代替。

> **转写说明**：末句「记住这个面试常考点」在原图中加粗。`[]`、`{}`、`set()`、`None`、`append` 均为行内代码样式。

## 图 image31

知识点：**迭代器的定义与两个特点**。

> 「迭代器是一个可以记住遍历位置的对象。」

迭代器对象从集合的第一个元素开始访问，直到所有元素被访问完为止。

迭代器有两个特点：

- 只能**往前**，不能**后退**。
- 用 `iter()` 把可迭代对象变成迭代器；用 `next()` 取下一个元素。

字符串、列表、元组都可以用来创建迭代器。迭代器对象既可以用 `for` 语句遍历，也可以用 `next()` 函数遍历。

> **转写说明**：首句为浅绿底引用块。「往前」「后退」加粗；`iter()`、`next()`、`for` 为行内代码样式。

## 图 image32

知识点：**`enumerate`——既要值又要下标时的标准写法**。

3、还有个常用工具：enumerate

写 `for` 的时候，如果你既要值又要下标，可以用 `enumerate()`：

```python
fruits = ['苹果', '香蕉', '橘子']
for i, fruit in enumerate(fruits):
    print(i, fruit)
```

输出：

```text
0 苹果
1 香蕉
2 橘子
```

`enumerate(可迭代对象)` 返回一个（下标，元素）的迭代器，省去你自己维护一个计数变量的麻烦。

> **转写说明**：标题为「3、还有个常用工具：enumerate」。代码块右上角有「复制」「▶ 试运行」按钮。
> 末段 `enumerate(可迭代对象)` 与「（下标，元素）」为浅灰圆角底行内代码样式。
