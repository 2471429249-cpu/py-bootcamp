## 图 note0

知识点：`if __name__ == "__main__":` 这一行判断的是"当前文件被直接运行，还是被 import 进别的文件"，只有被直接运行时才执行 `main()`。

**所以这行的意思**

代码块（左上角语言标签 `python`，右上角有「⟳ 复制」「⤓ 下载」两个按钮）：

```python
if __name__ == "__main__":
    main()
```

翻译成人话：

> 如果这个文件是被直接运行的，那就执行 main()；如果是被 import 的，就别执行。

> **转写说明**：图中 `__name__` 下方带一条下划线，是语法高亮／排版样式；`"__main__"` 两侧的引号在低分辨率下渲染得很细（形似 `*`），实为双引号 `"`。第二行 `main()` 前为 4 个空格缩进。

## 图 note1

知识点：`random` 模块常用取数函数对照表——按"想要什么"快速查用法和取值区间，重点是 `randint` 含两端、`randrange` 不含右端。

| 需求 | 用法 | 范围 |
| --- | --- | --- |
| 随机整数（含两端） | `random.randint(a, b)` | [a, b] |
| 随机整数（不含右端） | `random.randrange(a, b)` | [a, b) |
| 随机小数 | `random.uniform(a, b)` | [a, b] |
| 0~1小数 | `random.random()` | [0.0, 1.0) |
| 列表里选一个 | `random.choice(seq)` | — |
| 不重复选多个 | `random.sample(seq, k)` | — |

> **转写说明**：
> - 三列表头依次为「需求」「用法」「范围」。
> - "用法"一列在原图中为浅灰圆角底的**行内代码块**样式，故此处用反引号包裹。
> - 第 2 行区间是半开区间 `[a, b)`（右端小括号，不含右端）；第 4 行区间是 `[0.0, 1.0)`。
> - 最后两行的"范围"列是一道横线 `—`（表示不适用/未给区间），不是空单元格。

## 图 note17

知识点：给字符串加上 `f` 前缀就变成 f-string，`{i}` 会被替换为变量 `i` 的实际取值——这是 note16 那种写法的正确版本。

图幅很小（159×22 px），同样是行内片段：

```python
print(f"{i}")
```

> **转写说明**：与 note16 是同一对对比示例——`print("{i}")`（少写 `f`，原样输出 `{i}`）对 `print(f"{i}")`（正确插值）。图左侧有深色代码块的左边框。

## 图 note19

知识点：f-string 里用 `:<3` 指定"左对齐、占 3 个字符宽度"，再配合 `end="  "`，让九九乘法表各列宽度一致、排列整齐。

图中是深色代码块里的两行（含上一行被裁切的残影）：

```python
    # :<3 表示左对齐、占 3 个字符宽度，让表整齐
    print(f"{j}×{i}={i * j:<3}", end="  ")
```

> **转写说明**：
> - 两行均为 4 个空格缩进（应为嵌套循环体内部；本图是代码块的局部裁切）。
> - `{j}×{i}` 中的乘号为全角字符 `×`；等号后面是 `{i * j:<3}`，`*` 两侧各有一个空格。
> - `end="  "` 引号内的空白约两个空格宽度（低分辨率下无法 100% 精确到空格个数，此处按目测最接近的 2 个空格记录）。
> - 图片顶部还有一行只露出字符底部的残缺代码，无法辨认，未纳入转写。

## 图 note20

知识点：字符串反转的常见写法——切片 `[::-1]`（最优雅）、`reversed()` 配合 `"".join()`，以及中文等 Unicode 字符在反转时同样正确。

图中是一段文档字符串（docstring）的末尾：左侧有一条竖线（代码块／引用块左边框），内容从"练习点："开始，最后一行是收尾的三引号：

```python
练习点：
- 切片 [::-1]（Python 最优雅的反转写法）
- reversed() + "".join()
- 认识中文等 Unicode 字符在反转时也正确
"""
```

> **转写说明**：
> - 开头的 `"""` 在被裁切掉的上一行，图中只保留了结尾的 `"""`。
> - 三条练习点前用的都是半角连字符 `-` 加一个空格，呈条目列表样式。
> - 第 1 条的括号为全角括号 `（ ）`；`[::-1]` 因等宽字体渲染，冒号与减号间距看起来偏宽。
> - 第 2 条为 `reversed() + "".join()`，其中 `"".join()` 的空字符串是双引号，`+` 两侧各一个空格。
> - 该段整体为浅绿色等宽字体，是终端／代码块的暗色主题。
