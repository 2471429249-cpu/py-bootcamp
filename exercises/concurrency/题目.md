## 第 1 题 · 创建第一个线程

📖 **对应章节**：教学 03 →「1、线程的创建」

📝 **题干（照着步骤写）**

1. 写一个函数 `def hello():`，函数体两行：
   - 先 `time.sleep(1)`
   - 再打印 `子线程：我醒了`
2. 在 `main()` 里：
   - 用 `t = threading.Thread(target=hello)` 创建线程
   - 调用 `t.start()`
3. 紧接着（不要等）打印 `主线程：我结束了`

👀 **你应该看到**

先出现 `主线程：我结束了`，**1 秒后**才出现 `子线程：我醒了`。

💡 **提示**：线程只有调了 `start()` 才会真正跑起来。

❓ **想一想**

1. 为什么主线程没有等子线程就结束了？
2. 如果把 `t.start()` 改成 `t.run()`，会怎样？（试一下，对比输出顺序）

## 第 4 题 · `daemon`：主线程结束了子线程怎么办

📖 **对应章节**：教学 03 →「6、后台线程」

📝 **题干**

1. 写函数 `def countdown():`，循环 5 次：每次打印 `倒计时 i`，然后 `time.sleep(0.5)`
2. 写 `main()`：
   - 创建 `t = threading.Thread(target=countdown)`
   - `t.start()`
   - 主线程 `time.sleep(1)`，然后打印 `主线程结束`
3. **先按上面跑一次**（版本 A）
4. **再改一个地方跑一次**（版本 B）：在 `t.start()` **之前**加一行 `t.daemon = True`

👀 **你应该看到**

- **A**：`主线程结束` 打印后，程序**还要再跑一会儿**（子线程把 5 次倒计时打完才退出）
- **B**：`主线程结束` 之后程序**立刻退出**，倒计时只打印了 2 次左右

💡 **提示**：`daemon = True` 必须在 `start()` 之前设置。

❓ **想一想**

1. daemon 线程适合做什么任务？不适合做什么任务？
2. 为什么"写文件"的任务不能交给 daemon 线程？

## 第 5 题 · 用 `Lock` 保护共享计数器（⭐ 最重要的一题）

📖 **对应章节**：教学 03 →「3、线程同步与互斥锁」

📝 **题干**

先在文件顶部定义两个全局变量：

```python
counter = 0
lock = threading.Lock()
```

然后：

1. 写函数 `def add():`，循环 **20 次**，每次做这三行：
   ```python
   tmp = counter
   time.sleep(0.001)
   counter = tmp + 1
   ```
2. 在 `main()` 里：
   - 创建 **4 个**线程，都跑 `add`
   - 全部 `start()`，再全部 `join()`
   - 最后打印 `counter`
3. **先不加锁跑一次**，把结果记下来
4. **再把那三行用 `with lock:` 包起来**，再跑一次

👀 **你应该看到**

| 版本 | 期望 | 实际会看到 |
|---|---|---|
| 不加锁 | 80 | **约 20**（少了一大半！） |
| 加锁 | 80 | **正好 80** ✅ |

💡 **提示**：`with lock:` 会自动帮你加锁和解锁，包在它里面的代码同一时刻只有一个线程能执行。

❓ **想一想（这题想通就懂锁了）**

1. 不加锁为什么结果会变少？（"读"和"写"不是一步完成的）
2. `time.sleep(0.001)` 在这里起什么作用？（它让别的线程有机会插进中间）
3. 加锁之后程序变慢了吗？为什么还值得？

## 第 6 题 · `Condition`：等待和通知

📖 **对应章节**：教学 03 →「4、Condition 条件变量」

📝 **题干**（这题用最简版，不需要缓冲区）

先定义全局变量：

```python
cond = threading.Condition()
ready = False
```

1. 写 `def waiter():`
   ```python
   with cond:
       while not ready:
           print("等待中...")
           cond.wait()
       print("收到通知，开始干活")
   ```
   （`ready` 忘记加 `global` 会报错，注意一下）
2. 写 `def notifier():`
   ```python
   time.sleep(2)
   with cond:
       ready = True
       cond.notify()
   ```
3. `main()`：先 start 一个 `waiter` 线程，再 start 一个 `notifier` 线程，两个都 join

👀 **你应该看到**

先打印 `等待中...`，然后**停 2 秒**，之后才打印 `收到通知，开始干活`。

💡 **提示**：`cond.wait()` 会释放锁并挂起，直到被别人 `notify()` 唤醒。

❓ **想一想**

1. `wait()` 的时候，锁是拿着还是放开了？
2. 为什么判断条件要用 `while` 而不是 `if`？

## 第 8 题 · `Event`：发信号

📖 **对应章节**：教学 03 →「5、线程间通信」

📝 **题干**

1. 定义 `event = threading.Event()`
2. 写 `def worker():`
   - 先打印 `worker：等信号`
   - 然后 `event.wait()`
   - 再打印 `worker：收到信号，开工`
3. `main()`：
   - 起一个 worker 线程
   - 主线程 `time.sleep(2)`

💡 **提示**：Event 一开始是"未设置"状态，所以 `wait()` 会卡住。

## 第 10 题 · 进程的内存是独立的（很直观的一题）

```python
def set_x():

    x = 1
```

**实验 A（进程）**

1. `x = 0`（重置）
2. `p = Process(target=set_x)`，`p.start()`，`p.join()`
3. 主进程打印 `x`

**实验 B（线程）**

1. `x = 0`（重置）
2. `t = threading.Thread(target=set_x)`，`t.start()`，`t.join()`
3. 主线程打印 `x`

👀 **你应该看到**

- 实验 A：打印 **0**
- 实验 B：打印 **1**

💡 **提示**：`global x` 别忘了。

❓ **想一想**

# 选做 · `RLock`（章节里只提了一段，可以先跳过）

📖 **对应章节**：教学 03 →「3、线程同步与互斥锁」（最后一段 RLock）

📝 **题干**

1. 写 `lock = threading.Lock()`
2. 在同一个线程里**连续获取两次**：
   ```python
   print("第一次:", lock.acquire(timeout=1))
   print("第二次:", lock.acquire(timeout=1))   # ← 这里会拿不到
   ```
3. 再把 `lock` 换成 `threading.RLock()`，重复一次

👀 **你应该看到**

- 普通 `Lock`：第一次 `True`，第二次 **`False`**

💡 **提示**：用 `acquire(timeout=1)` 才不会把程序卡死。

❓ **想一想**：为什么"同一个线程拿同一把普通锁"会失败？什么情况下才真的需要 RLock？
